# TT426 Manual

Operator guides for the TT426 machine.

TT426 makinesi için operatör rehberleri.

## 📖 Documentation

<https://hm-info.github.io/tt426/>

- [Türkçe — Kısa kesim sonrası baskılar](https://hm-info.github.io/tt426/short_cut_clamps_tr.html)
- [English — Clamps after a short cut](https://hm-info.github.io/tt426/short_cut_clamps_en.html)

Each guide includes a PDF download, generated from the same Markdown during each build and not committed to the source branch.

Documentation check: `pip install -r requirements.txt` then `mkdocs build --strict`. PDF generation requires Pango, HarfBuzz Subset and DejaVu fonts; the Ubuntu packages are listed in the publishing workflow. Updates to `main` are published automatically to GitHub Pages.
